# Python AI Projects

This repository contains four Python-based projects that demonstrate different Generative AI and AI workflow concepts.

## Projects

### 1. Agent

The `agent` project demonstrates how an AI agent can make decisions and perform actions based on the user's query.

**Concepts covered:**
- AI Agents
- Decision making
- Tool usage
- Agent workflow
- LLM integration

---

### 2. Chat with Flow

The `chat with flow` project demonstrates a conversational AI application where the conversation is organized using a defined flow.

**Concepts covered:**
- Conversational AI
- LLM
- Flow-based execution
- User input and AI responses
- Python-based workflow

---

### 3. RAG

The `rag` project demonstrates Retrieval-Augmented Generation (RAG), where relevant information is retrieved from a knowledge source and provided to an LLM to generate a better answer.

**Concepts covered:**
- Retrieval-Augmented Generation
- Document processing
- Embeddings
- Vector search
- Context retrieval
- LLM-based answer generation

---

### 4. Semantic Search

The `semantic-search` project demonstrates semantic search using embeddings to find information based on meaning rather than only matching exact keywords.

**Concepts covered:**
- Text embeddings
- Semantic similarity
- Vector search
- Information retrieval
- Natural Language Processing

---

## Technologies Used

- Python
- Generative AI
- Large Language Models (LLMs)
- Embeddings
- Vector Search
- RAG
- AI Agents

## Purpose

The purpose of these projects is to learn and implement fundamental Generative AI concepts using Python. The projects cover different approaches including AI agents, conversational flows, Retrieval-Augmented Generation, and semantic search.
